Directory Check

Health-plan provider directories go stale: doctors move, change numbers or stop taking patients, and members hit dead ends. This checks each listing against what the provider's own pages say today, and shows the correction with its source.

Listings from the CMS NPI Registry
Web evidence from Exa

Load a set of listings to start. They come straight from the federal NPI registry, the same self-reported data many plan directories are built on.

Results are leads for a network-operations analyst, not final corrections. Sites that only republish the NPI registry are excluded from the search, since they would just repeat the listing back.
